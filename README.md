# Hi, I'm @joshua12312617 👋

I build small, complete things: every project here is self-contained,
documented, and tested — and several are built **from scratch** (a path
tracer with its own PNG encoder, a compression toolkit, a synthesizer).

## ⭐ Highlights

| Project | What it is |
|---|---|

| [**Squeeze**](https://github.com/joshua12312617/squeeze) | A compression toolkit from scratch: RLE, canonical Huffman, LZ77, and a bzip2-style BWT+MTF chain |

| [**RetentionLab**](https://github.com/joshua12312617/retentionlab) | A reproducible customer-churn data science study with leakage detection and profit curves |
| [**GitPulse**](https://github.com/joshua12312617/gitpulse) | Git knowledge maps and bus-factor analysis for any repository |
